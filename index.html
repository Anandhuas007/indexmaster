REFERENCE

Formulas

Quick reference for each index number.

Laspeyres

PL = (ΣP₁Q₀ / ΣP₀Q₀) × 100

Uses base-year quantities as weights.

Paasche

PP = (ΣP₁Q₁ / ΣP₀Q₁) × 100

Uses current-year quantities as weights.

Fisher

PF = (PL × PP)1/2

Geometric mean of Laspeyres and Paasche.

Marshall–Edgeworth

PME = [ΣP₁(Q₀+Q₁) / ΣP₀(Q₀+Q₁)] × 100

Uses the quantities from both years.
